
# Sales and Customer Analysis

## Overview
This repository contains SQL queries and analysis for customer behavior, product performance, and sales trends. The goal is to derive actionable insights from the `practise` schema, which includes tables such as `customers`, `products`, `sales` and `inventory`.

The SQL script includes queries for analyzing:
1. Customer behavior and spending patterns.
2. Product performance in terms of sales and revenue.
3. Sales trends, including peak days and revenue generation.

## How to Use
1. Clone the repository to your local machine.
2. Execute the provided SQL script (`queries.sql`) in your database environment.
3. Review the results of each query to understand customer behavior, product performance, and sales trends.

## Sample SQL Query
Here’s an example query to calculate the total revenue generated in the last month:
```sql
SELECT 
    SUM(s.total_amount) AS revenue_lastmonth
FROM practise.sales s
WHERE s.sale_date >= (
    SELECT MAX(sale_date) - INTERVAL '1 month'
    FROM practise.sales
);
```
